# Market scoring service

### Market Scoring Service — это сервис для оценки продавцов на маркетплейсе _"Forte market"_ на основе их данных. По запросу сервис получает определенную информацию об участнике через gRPC, вычисляет результаты с помощью бизнес-логики и возвращает код (int) в зависимости от соблюдения определенных условий.


## Instalation

```sh
make install
make export_path
make proto
```

or 

```sh
make all
```

## Run app

```sh
make run
```

### Scoring options

#### Для установки условий скорнинга см. config/config.json -> scoringConditions где

* activeProductsAge - товары должны быть активными и актуальными на сайте последние X дней

* orderCancellationBeforeConfirmation - % отмены продавцом по причине отсутствия товара в наличии, некорректной информации в прайс листе, брака или витринного товара в последние 30 дней

* orderCancellationDuringDelivery - отмены продавцом по причине отсутствия товара в наличии, некорректной информации в прайс листе, брака или витринного товара в последние 30 дней

* orderConfirmationTimeViolation - % заказов с нарушение продавцом временного регламента по подтверждению наличия заказа (3 рабочих часа)

* orderAssemblyTimeViolation - % заказов с нарушение продавцом временного регламента по подтверждению наличия заказа (6 рабочих часов)

* deliveryTimeViolation - % нарушений сроков доставки (в случае доставки собственными силами)

* sellerRating - Рейтинг продавца на маркетплейсе

* turnover - Средняя сумма оборотов на маркетплейсе за последние 3 месяца не менее X тенге

* isCreditBuyButton - Подключение кнопки "Купить в кредит" в случае наличия сайта

* isQRCreditOffline - Подключение функционала QR кредитования в случае наличия офлайн точек продаж



### Условия 

* Условия прописаны в config/conditions.xlsx

### Request
```sh
curl "http://localhost:8080/api/v1/data?bin=123"
```
__bin__ — _это уникальный идентификатор продавца на маркетплейсе, для которого нужно получить данные и провести оценку._

### Response

```sh
{"message": 1} # от 0 до 5
```

## Структура проекта
* src/service: Основная бизнес-логика приложения.

* src/transport: HTTP слой для обработки запросов.

* src/proto: Протофайлы для работы с gRPC.

* src/utils: Утилиты для работы с данными.

* src/config: Конфигурация приложения (например, пути к gRPC серверам и условия скоринга).
